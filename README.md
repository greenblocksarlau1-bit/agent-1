# وكيل وساطة wassata

وكيل يستقبل رسائل WhatsApp Business، ويحفظ المحادثات والعروض والزبناء في قاعدة بيانات.

## المرحلة الحالية (1)
- استقبال Webhook من Meta مع التحقق من التوقيع.
- حفظ الزبناء والرسائل ومنع تكرار الرسائل.
- تصنيف أولي (عرض بيع / استفسار / أخرى) وإنشاء مسودة عرض عند عرض بيع.
- رد ترحيبي تلقائي مرة واحدة لكل زبون.

## التشغيل المحلي
```bash
cp .env.example .env   # ثم املأ القيم
export $(grep -v '^#' .env | xargs)
python -m app.server
```
الخادم يعمل على `/webhook`. لاستقبال طلبات Meta محلياً استخدم نفقاً مثل ngrok أو cloudflared.

## الاختبارات
```bash
python -m unittest discover -s tests -v
```

## ربط Webhook في Meta
1. في تطبيق Meta، فعّل منتج WhatsApp واختر حقل `messages`.
2. Callback URL: `https://<عنوانك>/webhook`
3. Verify token: نفس قيمة `WHATSAPP_VERIFY_TOKEN`.

## الخطوات القادمة
- المرحلة 2: حوار ذكي عبر Claude API مع استخراج المعلومات عن العرض والزبون.
- المرحلة 3: توليد الأفيشات عبر مهارة الإنستغرام وقائمة موافقة المدير عبر WhatsApp.
- المرحلة 4: ترتيب العروض حسب الكفاءة والوفرة، وتقارير دورية عبر GitHub Actions.
